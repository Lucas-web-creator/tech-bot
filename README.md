
Este projeto foi desenvolvido como parte do desafio prático do bootcamp Formação ChatGPT for Devs da DIO (Digital Innovation One).

O TechBot é uma aplicação full-stack construída com Node.js, React e TypeScript, projetada para simular e estruturar as funcionalidades de um assistente de inteligência artificial, tendo o ChatGPT como principal referência arquitetural e de interface.

Tecnologias Utilizadas
Frontend: React + TypeScript

Backend: Node.js + TypeScript

Conceito: Integração e simulação de modelos de IA
